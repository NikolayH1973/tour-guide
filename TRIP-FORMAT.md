# Формат trip.json

Всё, что относится к конкретной поездке, лежит в `trip.json`. Движок (`app.js`) только рисует эти данные.
Пример — лондонский тур (3–9 декабря 2026). Телефон гида в шаблоне вымышленный.

## Язык интерфейса
- `locale` — язык надписей приложения: `ru` (позже `he`, `en`). Словарь лежит в `i18n/<locale>.json`.
- В словаре ключ → фраза; `{0}`, `{1}` — места для подстановок («В {0}» → «В Лондоне»).
- Не путать с `lang` — это язык озвучки разговорника (en-GB).

## Поездка
| Поле | Что это | Пример |
|---|---|---|
| `title` | название в шапке и во вкладке браузера | «Лондон на Рождество» |
| `eyebrow` | строка над названием | «3–9 декабря · Метрополь-Каспи · гид …» |
| `start`, `end` | даты, ГГГГ-ММ-ДД | `2026-12-03` |
| `tz` | часовой пояс места поездки (IANA) | `Europe/London` |
| `flights.out/back` | рейсы; с пересадками — список сегментов `legs` (у каждого свой номер, время, часовой пояс `tz`, время вылета `at`); `flights.durationText` — «Пять часов» | |
| `airport` | сбор в аэропорту вылета; `short` — коротко про вход | «вход 32» |
| `hotel` | один отель на весь тур (как в Лондоне): адрес, координаты `ll`, станция `tube` | |
| `hotels[]` | несколько отелей по датам: `city`, `from` (заезд), `to` (выезд), `name`, `address`, `phone`, `ll`. Приложение само показывает отель «на сегодня». Пустой список — «отели сообщат позже» | |
| `guide` | имя и телефон гида | |
| `days[]` | программа по дням | |
| `options[]`, `signupForm` | опции за доплату и форма записи | |

## Город и дом — с падежами
Русский текст требует падежей: «в Лондоне», «от Лондона», «к Лондону». Поле `prep` хранится вместе с предлогом: «в Лондоне», «во Вьетнаме», «на Кипре».
```json
"city": { "name": "Лондон", "gen": "Лондона", "dat": "Лондону", "prep": "в Лондоне",
          "flag": "🇬🇧", "mapSuffix": "London" },
"home": { "name": "Израиль", "gen": "Израиля", "dat": "Израилю", "prep": "в Израиле",
          "tz": "Asia/Jerusalem", "flag": "🇮🇱" }
```
`mapSuffix` дописывается к поиску на картах, чтобы не найти одноимённое место в другой стране.

## Деньги и язык
- `currency`: `symbol` (£), `homeSymbol` (₪), `rate` (курс по умолчанию), `childAge` (до скольких лет детская цена).
- `lang`: `code` (en-GB — язык озвучки), `voices` (предпочтительные голоса, регулярное выражение), `manner`, `accent` (фразы для текстов разговорника).

## Места
- `places[]` — места; у каждого `cat` (категория), `ll` (координаты), `route` или `direct` (как доехать).
- `categories`: `names` (названия), `icons`, `main` (кнопки на виду), `more` (под «ещё»).
- `shelves.season` — сезонная полка первой (ярмарки, пляжи…); убрать поле — полки не будет.
- `shelves.eveningCats`, `shelves.eveningSub` — что попадает в «Куда пойти вечером».

## Транспорт
- `transport.colors` — цвета линий `{ bg, fg }`.
- `transport.defaultLine` — линия, если у места указано только `direct` (число остановок).
- `transport.altHome` — вторая станция у отеля для другой линии (может не быть).
- `lines[]` — схема линий от отеля; `walks[]` — пешие прогулки.

## Помощь, викторина, разговорник
- `contacts[]` — важные телефоны; `help.backToHotel`, `help.theft[]` (пункты, можно с `<b>`), `help.links[]`.
- `quiz`: `title`, `about`, `themes`, `ranks`, `questions` (ok — номер правильного ответа с нуля).
- `phrasesBasics[]`, `phrases[]` — разговорник; `checklist[]`, `tips[]`, `apps[]`.

## Важно
- В JSON нет комментариев и подстановок `${…}` — только готовый текст.
- `help.theft` вставляется как HTML. Пока данные пишем мы сами, это безопасно. Когда текст начнут вводить агентства через редактор, его нужно будет очищать от опасных тегов.
- `manifest.json` (название при установке на экран) пока общий для всех туров — это следующий шаг.
